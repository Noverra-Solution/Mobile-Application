# Noverra Solution · Company Portfolio Website

A responsive, animated, single-page company portfolio based on the supplied *Noverra Company Profile & Software Portfolio (2026)*.

## Quick start

Open `index.html` in a browser. For local serving (recommended):

```bash
python -m http.server 8080
```

Then open http://localhost:8080.

## Deployment

The entire folder is deployable to Netlify, Vercel (static), GitHub Pages, or any conventional hosting. No API keys or server required for the portfolio.

## What's included

- Original-inspired orange connected-dot SVG mark and center-out opening animation.
- Animated hero, operational dashboard illustration, connected-capabilities ribbon.
- About, five platform pillars, interactive workflow, industries, web/mobile visual concepts, three software packages (Essential, Standard, Enterprise), differentiators and enquiry form.
- Responsive mobile navigation and scroll-triggered reveals.
- Reduced-motion accessibility and semantic sections.

## Before going live

1. Supply the **approved original vector logo**. The included `assets/logo.svg` is an approximate recreation, not official artwork. Replace with the exact logo if available.
2. Supply the official contact email/telephone/office address. The source document contains placeholders, so the website intentionally does **not** invent details.
3. Connect the enquiry form to a verified inbox/API before claiming messages are sent. Currently it prepares a copyable enquiry.
4. Replace illustration/mock data with verified screenshots when the production platform is ready. Visuals are labelled illustrative.
5. Industry photos are loaded from `images.unsplash.com` and require internet. Verify photography licensing and/or replace with approved local images for production.
6. Review brand spelling: the supplied document alternates **NOVERA** and **Noverra**. This site uses **Noverra Solution** following the latest conversation.
